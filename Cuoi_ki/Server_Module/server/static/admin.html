Hướng dẫn sử dụng

1 · Bật hệ thốngKhởi động Server, MQTT broker và chạy python -m pi.main trên Pi. Nhập Device ID, thường là pi01, rồi bấm Kết nối.
2 · Bật điều khiển tayĐưa một bàn tay rõ vào khung hình và giữ lòng bàn tay mở vài nhịp đến khi trạng thái chuyển sang “Sẵn sàng”.
3 · Điều khiển bằng gesture👍 giữ ngón cái để chụp sau đếm ngược; ✌ chuyển filter kế; ☝ chuyển filter trước; nắm tay hủy đếm ngược. Pinch bằng ngón cái–trỏ để zoom.
Giữ mỗi gesture khoảng 4 frame; confidence cần đạt 60%. Sau lệnh, thả tay ra rồi mới lặp lại. Nút web “Yêu cầu chụp” và nút vật lý (nếu đã nối) vẫn có thể chụp thủ công.
Dữ liệu được làm mới định kỳ từ Server · Không cần cài thêm frontend package
